SLEd — Help

Getting started

  • Import a SillyTavern lorebook JSON to load it.
  • New Lorebook creates a fresh one. The name you type in the header is used as the export filename.
  • Your work is auto-saved in this browser — close the tab and come back to pick up where you left off.

Editing entries

  • Click an entry in the sidebar to open it in a tab. Open more entries to compare; click a tab title to switch.
  • The form auto-saves to memory as you type. The orange dot (●) marks entries that differ from the last imported/exported state.
  • The save icon commits the current form and clears the dot for that entry. Export writes the lorebook back out to a file.

Sidebar quick actions

  • Hover an entry (or tap on touch) to reveal: insert above, insert below, duplicate, enable/disable, delete.
  • Use the number on the left of each entry to change its position; the rest of the list re-sequences automatically.
  • Tick the checkbox on multiple entries to select them, then drag any selected entry to move the whole group at once.
  • The zoom dropdown switches between Compact / Normal / Detailed views.

Merging

  • Click the Merge action to pick another lorebook file. A modal lists its entries — tick the ones you want, then confirm. UIDs and orders are reassigned to avoid collisions.

Search & Replace

  • Open with the search icon or Ctrl+H. Choose case sensitivity, whole words, regex, and the scope (all fields / content / keywords / titles).
  • In the search input: Enter finds all, Shift+Enter replaces the current match, Ctrl+Enter replaces all.
